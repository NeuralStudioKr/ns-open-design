## 토큰 패턴

```css
:hover → bg-subtle / accent
:active → bg-muted / accent-strong (primary)
:focus-visible → outline 2px solid var(--accent); outline-offset 2px
transition → var(--dur-quick) var(--ease-out) where missing
```

primary plugin/submit: `color: #fff` → 유지하되 active는 `--accent-strong` (filter brightness 대신).
