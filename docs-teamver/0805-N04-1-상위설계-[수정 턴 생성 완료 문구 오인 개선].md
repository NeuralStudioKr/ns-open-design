# 0805-N04-1 상위설계 — 수정 턴 생성 완료 문구 오인 개선

**날짜:** 2026-08-05  
**브랜치:** `staging`

## 문제

AI **수정** 요청 후에도 채팅에 「슬라이드 초안이 생성되었습니다.」가 보인다.

## 원인 (현재 구현)

1. **합성 lead:** `teamverCompletedArtifactLeadCopy` / live lead가 artifact `type`만 보면 full `deck` 응답 시 생성 카피.
2. Live 경로는 `messageLooksLikeSlideEditTurn`(preTurn HTML)을 쓰지 않음.
3. 모델이 「생성되었습니다」류 자연어를 쓰면 `hasVisibleAssistantText`가 true가 되어 합성 수정 lead가 억제되고, 잘못된 생성 prose가 남음.

## 목표

수정 턴(기존 deck HTML baseline / deck-patch)이면 진행·완료 문구를 항상 **수정 반영** 카피로 맞추고, 생성 완료 자연어는 숨기거나 대체한다.

## 비목표

- 모델이 full deck을 내는 동작 자체를 막지 않음 (별도 prompt 품질).
- 생성 턴의 「초안이 생성되었습니다」 문구 제거.

## 성공 기준

| # | 기준 |
|---|---|
| S1 | preTurn에 deck.html이 있는 턴에서 full `deck` 스트림 중에도 「수정을 반영하고 있습니다」 |
| S2 | 동일 턴 완료 시 「수정이 반영되었습니다」 |
| S3 | 모델이 「슬라이드 초안이 생성되었습니다」만 쓴 수정 턴에서도 생성 문구 미노출 |
| S4 | 진짜 생성 턴(preTurn HTML 없음)은 기존 생성 카피 유지 |
