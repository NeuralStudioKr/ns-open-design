## 1. 호출 그룹

### 1.1 Boot / 세션 (필수)

| # | Path | 역할 | 주요 코드 |
|---|------|------|-----------|
| 1 | `GET /api/version` | FE–daemon 버전 정합 | `App.tsx` |
| 2 | `GET /api/health` | daemon 생존 | boot |
| 3 | `GET /api/analytics/config` | 분석 설정 | analytics |
| 4 | `GET /teamver-bff/auth/session` | 로그인 세션 | BFF auth |
| 5 | `GET /teamver-bff/auth/session-probe` | cookie / nginx auth | auth gate (coalesce·cache) |
| 6 | `GET /teamver-bff/runtime-config` | BYOK·모델 등 runtime | App boot |
| 7 | `GET /api/app-config` | 앱 설정 | `state/config.ts` |

**개선 여지(낮음):** 이미 probe coalesce·app-config echo PUT 스킵 있음. 추가 축소는 신중.

### 1.2 Home 카탈로그 (EntryView)

| # | Path | 역할 | 주요 코드 |
|---|------|------|-----------|
| 8 | `GET /api/skills?catalog=slide` | 슬라이드 스킬 | EntryView / App |
| 9 | `GET /api/design-templates?mode=deck&limit=24` | 템플릿 | App / Templates |
| 10 | `GET /api/design-systems` | 디자인 시스템 | App |
| 11 | `GET /api/plugins?mode=deck&limit=24` | 플러그인 목록 | plugins home |
| 12 | `GET /api/plugins/example-simple-deck` | 예시 플러그인 상세 | plugins home / HtmlSurface |

**개선 여지(중간):** 카탈로그 parallel은 유지하되, 미사용 탭 지연 로드·예시 플러그인 상세를 목록 payload에 합치기 검토.

### 1.3 프로젝트 목록·메타 (배치)

| # | Path | 역할 | 주요 코드 |
|---|------|------|-----------|
| 13 | `GET /teamver-bff/projects` | registry 목록 | projects / BFF |
| 14 | `POST /api/projects/status-hints` | 상태 뱃지 배치 | `state/projects.ts` |
| 15 | `POST /api/projects/cover-hints` | 커버 힌트 배치 | `projectCoverLoader.ts` |
| 16 | `POST /teamver-bff/projects/batch/outputs/latest` | 최근 산출물 | publish chip (microtask coalesce) |

**개선 여지(낮~중):** hints·outputs는 이미 배치/coalesce. registry 창 크기와 hints id 집합 정렬이 핵심.

### 1.4 카드 커버 워터폴 (Recent / 뷰포트)

실측(2026-08-06, Recent ~6장 가시):

| Path 패턴 | 횟수 | 의미 |
|-----------|------|------|
| `GET /api/projects/:id/files` | **1** | cover-hints miss → `/files` fallback ([0805-N06](./0805-N06-1-상위설계-[프로젝트%20썸네일%20미표시%20회귀].md) 복구) |

**코드:** `useLazyProjectCover` · `prefetchHomeProjectCovers` · `ProjectCardHtmlCover` · `projectCoverLoader.ts`

4. 카탈로그 defer / `example-simple-deck` 합치기 — 미착수
5. offscreen prefetch 상한·동시성 재조정 (현재 `/files` concurrency cap=3)

## 3. 재실측 방법

1. Chrome DevTools → Network → **Disable cache** · 시크릿 또는 hard reload.
2. Filter: `Fetch/XHR` only · Domains: `stg-design.teamver.com`.
3. home `/` 진입 직후 ~3s 창의 요청을 복사.
4. 이 문서 §2에 날짜·N(가시 카드 수)·특이점(추가 `/files`, probe 중복 등)을 **새 절**로 append.
5. 개선 PR은 before/after 요청 수를 이 baseline과 비교해 구현현황에 기입.
