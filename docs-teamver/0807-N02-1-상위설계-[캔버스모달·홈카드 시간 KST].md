# 0807-N02-1 상위설계 — 캔버스 모달·홈 카드 시간

## 증상

1. 「캔버스에서 슬라이드 만들기」모달의 수정 시각이 KST로 안 보임 (UTC naive / revision id 노출).
2. 연속 생성한 슬라이드 홈 카드 상대시간이 서로 다름 (11분 전 / 이틀 전 / 3일 전).

## 원인 가설

1. `formatUpdatedAt`이 `timeZone: Asia/Seoul` 없이 포맷하고, 파싱 실패 시 revision id를 raw로 표시. URL/merge가 `updatedAt || revision`.
2. Main Canvas naive ISO(`…T07:11:00` without Z)를 local로 해석 → UTC 벽시계가 그대로 보임.
3. 홈 카드는 registry `updatedAt` 상대시간 — 재등록/기존 row가 touch 되지 않으면 예전 시각이 남음. seconds/ms·Date 객체 미정규화도 가능.

## 범위

- FE timestamp util + 모달/ registry map
- design-api register 시 `updated_at` touch
