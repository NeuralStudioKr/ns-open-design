# 0805-N03-1 상위설계 — 채팅 UI 푸터·큐·플러그인 CTA 폴리시

**날짜:** 2026-08-05  
**선행:** [0805-N01](./0805-N01-1-상위설계-[채팅%20UI%20토스트·파일%20액션%20폴리시].md) · [0805-N02](./0805-N02-1-상위설계-[채팅%20UI%20인터랙션·CTA%20폴리시].md)

## 문제

N01/N02 이후에도 채팅 내 다수 컨트롤이 hover만 있고 `:active`/`:focus-visible`이 비대칭이다.

1. Plugin action CTA  
2. Assistant footer (copy/feedback/submit)  
3. QueuedSendStrip 액션  
4. Conversation picker (trigger/New/row/del)  
5. Composer Stop · attachment chips · staged-remove  
6. Tool disclosure (action-card-toggle, file-ops-toggle, op-open)

## 목표

N02와 동일 토큰 패턴으로 press/focus 대칭. 레이아웃 재설계 없음.

## 성공 기준

각 대상 셀렉터에 `:active` + `:focus-visible`(또는 기존 outline 보완) + primary는 `--accent-hover`/`--accent-strong`.
