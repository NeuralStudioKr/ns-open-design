# 0807-N03-1 상위설계 — 캔버스→PPT 완료 후 「작성 중」 잔존

## 증상 (staging)

캔버스→슬라이드(캔버스 to PPT) 생성 완료 후에도 왼쪽 채팅 어시스턴트 메시지에 **「작성 중」** 이 남음.

- 미리보기·`deck.html`·푸터 **「완료됨」** 은 정상
- 완료 lead(「슬라이드 초안이 생성되었습니다」) 미표시

## 가설

1. 시스템 프롬프트가 artifact 전 **짧은 진행형 상태 문장**(예: `작성 중`)을 허용.
2. `looksLikeDeckCreateProgressProse` 가 덱 키워드 없는 bare `작성 중` 을 progress 로 인식하지 않음.
3. 해당 prose 가 `hasVisibleAssistantText` 로 남아 `shouldSynthesizeTeamverCompletedArtifactLead` 가 false → 완료 lead 억제, progress 문구만 잔존.

## 범위

- FE: progress prose 판별 보강 + 스트림 종료 후 hide + completed lead 재개
- 단위 테스트

## 비범위

- 모델 프롬프트 전면 개편, daemon 변경
