## 코드 변경 요약

### `packages/contracts/src/template-clone-fill.ts`

- `stripClassBlocks`: non-greedy regex → **depth-aware** iterator.
  - 이전: `<div class="alt">…<div>…</div>…</div>` 에서 첫 `</div>` 로 close → 잔존 tag-soup 이 downstream heuristic 을 오작동시킴.
  - 이후: 동일 tag 의 open/close 를 세면서 outer close 까지 완전 제거. `<foo/>` self-closing 은 depth 유지.
- `stripLeftoverTemplateDemoCopy` 클래스 목록에 IB pitch-book 계열 추가: `alts-grid`, `alt`, `next`, `step`, `stamp`, `dcf-asm`, `kpi-grid`, `ff-chart`, `ff-track`, `ff-tick`, `ff-axis`, `ff-row`, `market-cols`.
  - `chart`, `legend`, `chartbox`, `pc`, `stat`, `badge`, `foot`, `kpi` 는 **의도적 제외** — 다른 공식 템플릿에서 통용되는 general-purpose class 이며 `template-clone-official-leftover` 계열 시각적 회귀 위험.
- 새 함수 `hoistCloneSlidesOutOfFlexTrack(html)`:
  1. `<div class="stage|deck-stage|slides-container|deck-track"|id="…">` wrapper 를 depth-count 로 찾고, 내부에 최소 2개 `<section class="slide">` 이 있으며 그 외 요소가 없으면 wrapper 를 제거.
  2. 그 다음 pass 로 `<div class="deck"|id="deck">` letterbox 도 같은 규칙으로 unwrap.
  3. 두 단계 사이에서 `.chrome / .deck-nav / .slide-counter / .nav-dots` 는 “dead” 로 취급해 depth-strip → slide-only 판정 통과. 슬라이드 카운터 텍스트(`01 / 09`)도 함께 사라짐.
- `buildTemplateClonedDeckHtml` 마지막에 `hoistCloneSlidesOutOfFlexTrack(out)` 호출 (`normalizeTemplateCssForFixedCanvas` 뒤, `injectTeamverSizeStyle` 앞).
