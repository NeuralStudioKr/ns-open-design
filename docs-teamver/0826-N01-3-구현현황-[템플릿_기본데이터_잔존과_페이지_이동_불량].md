## 코드 변경 요약

### `packages/contracts/src/template-clone-fill.ts`

- `stripClassBlocks`: non-greedy regex → **depth-aware** iterator.
  - 이전: `<div class="alt">…<div>…</div>…</div>` 에서 첫 `</div>` 로 close → 잔존 tag-soup 이 downstream heuristic 을 오작동시킴.
  - 이후: 동일 tag 의 open/close 를 세면서 outer close 까지 완전 제거. `<foo/>` self-closing 은 depth 유지.
- `stripLeftoverTemplateDemoCopy` → `stripNonSlotWrappers` (F4). 클래스 목록 제거. 슬롯 조상(`.slide-inner` / `.body`)은 유지하고 disjoint leftover(prose ≥ 2 또는 빈 카드 그리드)만 삭제.
- F6: 제목 슬롯 클래스(`hero-title`/`display`/`headline` 등). wrapper 에 `dl|ul|ol|pre|code`. 아웃라인 리스트는 첫 번째만 슬롯. empty-slot early-return 없음.
- 새 함수 `hoistCloneSlidesOutOfFlexTrack(html)`:
  1. `<div class="stage|deck-stage|slides-container|deck-track"|id="…">` wrapper 를 depth-count 로 찾고, 내부에 최소 2개 `<section class="slide">` 이 있으며 그 외 요소가 없으면 wrapper 를 제거.
  2. 그 다음 pass 로 `<div class="deck"|id="deck">` letterbox 도 같은 규칙으로 unwrap.
  3. 두 단계 사이에서 `.chrome / .deck-nav / .slide-counter / .nav-dots` 는 “dead” 로 취급해 depth-strip → slide-only 판정 통과. 슬라이드 카운터 텍스트(`01 / 09`)도 함께 사라짐.
- `buildTemplateClonedDeckHtml` 마지막에 `hoistCloneSlidesOutOfFlexTrack(out)` 호출 (`normalizeTemplateCssForFixedCanvas` 뒤, `injectTeamverSizeStyle` 앞).

## F7 — AI 생성 덱 5종 회귀 (2026-08-27)

**입력:** 사용자가 렌더된 실 HTML 첨부. 한국어 브리프 “영어 회화 공부, 연습 팁에 대한” + ib-pitch-book 팔레트로 AI가 자유 emit 한 `s-cover`/`s-chapter`/`s-data` 계열 슬라이드. 5개 결함:

- **Q1** 슬라이드 2가 `<section class="slide s-chapter"...></section>` — 완전히 빈 검은 사각.
- **Q2** 슬라이드 3의 `<h1>왜 회화는<br>공부가 아니라<div class="lede">발화 근육이 필요...</div></h1>` — heading 안에 block div가 중첩되어 브라우저가 heading font로 lede를 렌더.
- **Q3** 슬라이드 4가 `grid-template-columns: repeat(4,1fr)` 인데 카드는 하나 (Shadowing). 오른쪽 75%가 빈 밴드.
- **Q4** 슬라이드 5의 `<div>Shado</div></div></h></div></div></section>` — 단어 중간 절단 + 존재하지 않는 `</h>` 태그.
- **Q5** subhead `발화 회로 를 단련` 조사 공백, cover meta rows/foot에 brief 원문 raw `영어 회화 공부, 연습 팁에 대한` 노출.

**결정:**

1. `template-clone-fill.ts` 는 저자 catalog 경로만 다룬다. AI freeform emit 은 별도 heal 파이프가 필요 → `heal-ai-generated-deck.ts` 신설 (F7-a).
2. 파이프 배선은 srcdoc.ts (deck preview) 와 deckPdfExport.ts (standalone export) 둘 다에 걸어 export 다운로드도 동일 heal 반영 (F7-b).
3. round35 (`<ul><li>` padding 8px) 와 round437 (`.5rem+4px` 12px thin) 회귀도 같은 슬라이스에서 소진: list-item 태그는 padding ≥4px 물리값에서 kit-card 바인딩. mixed 12px 물리는 thin, 물리 합 ≥13px 이면 card. 루프435~514 세대의 “12px mixed=card” 테스트 11건은 round437 SSOT에 정렬 (F7-c).
4. AI가 catalog HTML을 emit 할 가능성은 낮지만, 모든 heal은 shape-based 로 저자 CSS 를 절대 건드리지 않는다 (`visibleText < 2` + `direct child count` + 명시 slot class 만 기준).

**모듈 세부:**

- `dropEmptyLikelyDeckSlides` — 첫 슬라이드 제외. `<svg|img|video|canvas|iframe|picture|figure>` 있으면 유지. attrs 안 `background(-image)`/`gradient` 스타일이면 motif shell 로 판단해 유지.
- `unnestHeadingBlockChildren` — heading 앞에 텍스트가 있고 block child 가 있으면 heading을 그 앞에서 닫고 block을 형제로. `<h1><div>only-child</div></h1>` 처럼 block이 first-child 인 경우는 no-op.
- `shrinkOverAllocatedRepeatGrid` — depth-1 자식만 셈. 카드 내부 나열이 카운트 부풀림 방지.
- `scrubTruncatedAiTagSoup` — `<\/?h(?![1-6])[\s>/]/` 패턴만 정확히 제거.
- `normalizeHangulParticleGaps` — 조사 화이트리스트(를/을/이/가/은/는/에/의/과/와/도/로/으로/…) 기반. 이 목록 밖의 공백은 유지.
- `scrubBriefLeakFromMetaSlots` — 슬롯 클래스 화이트리스트(v/conf/kicker/brief/summary/note/lede)에 완전 일치일 때만 blank.
