# 0916-N03-1 상위설계 — Block Frame 발명 hero 셸

**날짜:** 2026-09-16 · **루프:** 539

## 체감

Block Frame 표지에서 MiniMax가 킷에 없는 클래스를 만든다.

- `.hero-title-highlight` — 줄바꿈 글자가 하이라이트 박스 밖으로 잘림
- `.download-card` / `.platform-card` — Desktop/Android/iOS 빈 카드, iOS에 사업자 고지
- `Enterprise 데모` 영어 CTA

## 정책

- 하이라이트 span은 텍스트만 남기고 푼다.
- 빈·제목만·법적 고지뿐인 platform 카드는 제거한다.
- 일반 영어 CTA는 한국어로 바꾼다. 영문 카탈로그 example은 대상이 아님(필러에 발명 클래스 없음).
