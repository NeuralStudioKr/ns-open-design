## 1. 목표 / Non-goals

| | |
|--|--|
| 목표 | flow 타깃 body-drag → in-place `position:absolute` 승격 + left/top 이동 |
| Non-goals | re-parent, DOM reorder, 확인 모달, 회전 |

---

## 2. 자격

```ts
canPromoteTarget(target): boolean  // static|relative|sticky, !slideRoot, size ok
canMoveOrPromoteTarget = canMoveTarget || canPromoteTarget
```

overlay `data-movable` / grab 커서는 `canMoveOrPromoteTarget`.

---

## 3. 좌표

bridge `targetFrom`에 추가:

- `offsetLeft` / `offsetTop` ← `el.offsetLeft` / `el.offsetTop` (offsetParent 기준)

`startPositionFromTarget`:

1. explicit `styles.left` / `styles.top` px
2. else `offsetLeft` / `offsetTop`
3. else `rect.x` / `rect.y` (fallback)

---

## 4. 스타일 계약

`ManualEditStyles` + bridge `styleProps`에 `position` 추가.

승격 시 payload (`promoteMoveStyles`):

```ts
{
  position: 'absolute',
  left, top,           // computeMove 결과
  width, height,       // start rect 스냅
  margin / margin*: '0' 또는 '',
  right: '', bottom: '',
}
```

이미 absolute/fixed면 52 `moveResultToStyles`만 사용 (position 미기록).

---

## 5. 세션

52 move 세션과 동일. 차이:

- `stylesBefore`에 position·width·height·margin* 포함 (promote 세션)
- preview/commit에 promote 필드 merge
- cancel 시 해당 키 keyed rollback
- 임계 미만·preview 없음 → no-op (기존 계약)

history label: `Move: {label}` 유지 (승격+이동 1 entry).

---

## 6. 패널

static 등: POSITION inactive 섹션 문구를  
`manualEdit.positionPromoteOnDrag` 로 교체 (“드래그하면 absolute로 풀어 이동합니다”).

---

## 7. 테스트

| 층 | 케이스 |
|----|--------|
| unit | `canPromoteTarget`, `promoteMoveStyles`, startPosition offset fallback |
| overlay | static body-drag preview includes position:absolute |
| Playwright | resize-box drag → source `position:absolute` + left/top; Esc 불변; undo 1스텝 |

---

## 8. requirements

non-goal 문구에 “in-place absolute promote (no re-parent) — 53” 한 줄 추가.
