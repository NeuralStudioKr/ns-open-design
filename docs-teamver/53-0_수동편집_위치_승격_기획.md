## 1. 한 줄 요약

flow 레이아웃(`static`/`relative`/`sticky`) 요소를 Manual Edit에서 **본체 드래그하면**  
DOM 부모는 유지한 채 `position:absolute`로 **승격**하고, 이어서 52와 같이 `left`/`top`으로 옮긴다.

---

## 2. 사용자 문제

| As-Is (52 이후) | Pain |
|-----------------|------|
| absolute/fixed만 이동 | 대부분 HTML 카드·문단은 static → “못 옮김” 힌트만 |
| 패널에 POSITION 비활성 | 승격 수단이 없어 사용자가 CSS를 직접 넣어야 함 |

---

## 3. 성공 기준

1. static(등) 타깃에서도 overlay 본체가 grab이며, 의미 있는 드래그(≥2px) 시 `position:absolute` + `left`/`top` + 고정 `width`/`height`가 소스에 남는다.
2. 승격 순간 시각적 점프가 없다(offsetParent 기준 좌표 스냅).
3. Esc/임계 미만은 승격·이동 모두 디스크에 안 남긴다.
4. history/undo **1스텝**으로 승격 전 상태로 복귀 (`file-viewer-undo`).
5. **re-parent / DOM 순서 변경 없음** (requirements non-goal 유지).

---

## 4. 범위

### In scope (Phase 1)

| 항목 | 설명 |
|------|------|
| 자격 | `static` / `relative` / `sticky` Manual Edit 타깃 (slide root 제외) |
| 제스처 | 52와 동일 body-drag; 임계 통과 시 promote+move 동시 preview/commit |
| persist | `set-style`: `position`, `left`, `top`, `width`, `height`, margin 0, right/bottom 클리어 |
| 좌표 | bridge `offsetLeft`/`offsetTop` (offsetParent 기준) |
| UX 힌트 | 패널 POSITION: 승격 안내 i18n |

### Out of scope

- re-parent / flex order / grid 재배치
- 확인 모달(1차는 드래그=의도)
- 멀티셀렉트·스냅 가이드
