# 0914-N02-1 상위설계 — 표지 브랜드 Latin 보존

## 문제

한글 brief(`www.teamver.com 사이트 분석…`)로 서비스 소개 덱을 만들면 표지 제목이 `팀버` / `팀버 소개`로 나온다. 제품 브랜드 표기는 Latin `Teamver`여야 한다.

## 원인

루프389 `polishUrlSiteCoverTitle`이 한글 brief일 때 host `teamver`를 Hangul로 강제. `neuralstudio`는 Latin 유지 — teamver만 특수 케이스. 표지 heal/outline synth가 이 폴백을 전파.

## 목표

- URL/brief 유래 표지·덱 타이틀: `Teamver` / `Teamver 소개`
- 프롬프트: 고유명사 phonetic Hangulize 금지
- 기존 fixture HTML에 남은 `팀버` 문자열은 레이아웃 테스트용으로 유지 가능 (신규 polish 경로만 Latin)

## 비범위

- 표지 킷 레이아웃 rebuild / body-first 폰트 순서 (P1, 후속)
- 모든 기존 덱 HTML의 `팀버` 일괄 치환
