## 관측 3가지 · 근본 원인

### (1) 저장 실패 · `artifact_regression / slide-count` (블로커)

`ProjectView.tsx:6451 findClientSlideCountRegression`가 다음 케이스를 거절:
- prior가 이미 **synth outline만으로 채워진** block-frame 10-slide 덱
- 새 fill이 6-8 slide짜리 짧지만 온전한 덱

`allowSlideCountReduction` 우회 조건:
- `runTemplateCloneContentFillRef.current` (JSON slot-fill 턴)
- `runTemplateClonePromptFillRef.current` (prompt-fill 턴)
- `priorIsCloneLookSeedFile` (prior manifest.templateClonedDeckSeeded)
- `priorDeckAllowsCompactReplacement(priorHtml, brief)` = leftover / scrubbed catalog / unfilled example

문제: 이번 케이스는 위 4개 모두 false — prior가 이미 fill됐고 seed metadata가 지워졌으며, catalog leftover 검출기(`looksLikeLeftoverTemplateDemoDeck` 등)는 topic이 스며든 synth outline은 leftover로 잡지 못한다.

byte-size 가드(`findClientArtifactRegression`)에는 **prior가 low-substance면 bypass**하는 로직이 line 3081에 이미 있는데, slide-count 가드에는 그게 없다. 이 비대칭이 원인.

**수정**: `findClientSlideCountRegression`에 `isLowSubstanceSlideDeckArtifact(priorHtml, healBrief, healTitle)` prior bypass 추가. topic-specific real content로 채워진 prior는 여전히 substance-rich로 판정되어 짧은 초안이 거절됨 (사용자 원칙 유지).

### (2) 루프543 rotation salt가 사용자 카피에 노출 (긴급)

`packages/contracts/src/template-clone-fill.ts` 루프543에서 도입한
`decorateSynthLineWithSlideLabel` / `decorateSynthItemTitleWithSlideLabel` /
`lead — label` 세 개가 slideCount > templates.length(6) 일 때 body/items/lead에
slide label(`요약`, `핵심 포인트` 등)을 그대로 삽입.

사용자 실물:
```
문제 · 요약 — 사용자가 반복해서 겪는 핵심 불편과 전환 비용을 먼저 정의 (요약)
사용자 · 요약 — … (요약)
Teamver가 풀어야 하는 문제 — 요약
```

내부 인덱스가 사용자에게 그대로 보이는 UX 버그. 반복 방지는 이번 R1 이후 topic이 body에 스며들면서 (`글을 매력적으로 쓰는 팁` 등이 각 카드에 등장) 이미 충분히 해소됨. rotation salt는 이제 순수 노이즈.

**수정**:
- `synthesizeTemplateCloneSlideBody`의 rotation salt 3종 제거.
- `decorateSynthLineWithSlideLabel` / `decorateSynthItemTitleWithSlideLabel` 함수도 dead code로 삭제.
- 이미 저장된 HTML에서 trailing salt(`· 요약`, `(요약)`, `— 요약`, `— 핵심 포인트` 등 `TEMPLATE_CLONE_GENERIC_SECTION_LABELS` 만) 벗기는 healer.

### (3) prompt seed에 "짧게 내지 말 / 장 수 유지" 지시 부재

루프544 `SLIDE_DECK_UNIQUE_SLOT_COPY_INSTRUCTION`에 "if two slides would end up
with identical body strings, rewrite one with a distinct angle" · "majority
share the same body sentence is a failed deliverable" — 모델이 이를 회피하려
슬라이드 수를 줄이는 방향으로 오작동할 위험.

**수정**: 같은 상수에 "이 유일성을 지키기 위해 슬라이드 수를 줄여 통과하지
말 것. 템플릿의 슬라이드 장 수를 유지하고, 필요하면 각 슬롯의 각도를 바꿔
표현하라"를 명시. 문자열 pin.
