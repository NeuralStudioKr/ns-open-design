## 3. 정책 (루프473)

1. **서비스 소개** brief(`looksLikeTemplateCloneServiceIntroBrief`)에서 cover lead를 고를 때, brief·outline 앵커에 **더 나은 한 줄**이 있으면 `{topic} 한눈에`를 쓰지 않는다.
2. 우선순위(위에서 아래로, 첫 usable):
   1. 제품 tagline / one-liner (`Brand — promise`, `Smarter & Faster` 등)
   2. Source preview 첫 실문장
   3. 문제·맥락 한 줄 (problem one-liner)
   4. headings 중 promise·가치 문장
   5. 최후: `{topic} 한눈에` (비서비스·짧은 토픽·앵커 없음)
3. 비서비스 소개 / 짧은 토픽 덱은 기존 `한눈에`·generic outline을 **유지**.
4. lead chooser는 contracts 순수 함수 + 단위 테스트. Zhangzara gate / layout smoke **비범위**.
5. Studio/Creative leftover denylist(54-2 #4)는 **이번 슬라이스 비범위**(다음 추천으로 이월).

## 4. 성공 기준

- service-intro + preview/tagline 앵커 → cover lead가 `…한눈에`가 아님
- URL-only service-intro(앵커 없음) → 최후 `한눈에` 허용
- 일반 Expo 등 free-form → 기존 outline·lead 회귀 유지
- unit: lead chooser + deterministic fill 회귀
