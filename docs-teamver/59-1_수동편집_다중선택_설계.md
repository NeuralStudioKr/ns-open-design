## 2. Bridge 계약

### Canvas click (`od-edit-select`)

```ts
{ type: 'od-edit-select', target: ManualEditTarget, additive?: boolean }
```

- `additive = shiftKey || metaKey || ctrlKey`
- Host: `nextManualEditSelectionIds(current, id, additive)` → toggle/replace

### Host → iframe (`od-edit-selected-target`)

```ts
{
  type: 'od-edit-selected-target',
  id: primaryId | null,
  ids: string[],
  primaryId: string | null,
  hostChrome: boolean, // ids.length === 1 일 때만 resize overlay
}
```

- `ids.length > 1` → `setSelectedTargets` (union dashed chrome, `data-od-edit-primary` on primary)
- 단일 → 기존 `setSelectedTarget` + `hostChrome`

## 4. Style 배치 저장

1. `handleManualEditStyleChange(ids[], styles)` — 모든 id에 live preview
2. `flushManualEditStyleSave` — `buildManualEditStylePatchesForTargets` → `applyManualEditBatch`
3. `applyManualEditBatch` — N patch를 source에 순차 적용 후 **revision 1회**
4. undo — revision 1 step으로 전체 롤백 ([50](./50_undo_redo_설계.md))

**Selection boundary:** pending `targetIds`가 바뀌면 `shouldFlushManualEditStylesOnSelectionBoundary` → force flush.
