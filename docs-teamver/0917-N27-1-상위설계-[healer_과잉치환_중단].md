# 0917-N27-1 상위설계 — healer가 MiniMax 문장을 주제-템플릿으로 덮지 않게 한다

**날짜:** 2026-09-17 · **루프:** 554

## 한 문장 진단

v1.4.15는 MiniMax가 seed 10장을 직접 채운 결과물이었다. 지금은 MiniMax가 짧게 내거나 leftover를 남기면 **서버 힐러/synth가 제목·본문을 템플릿으로 덮어써서** `주제`, `소개 2`, `쓰는 순서를 쓰는 순서` 같은 문장이 완성본처럼 저장된다. 그래서 장수는 맞아도 품질이 훨씬 낮다.

## 체감 (사용자 첨부 Product Launch HTML)

| v1.4.15 | 지금 (루프551–553 이후) |
|---|---|
| MiniMax가 LOOK seed 10장 슬롯을 직접 채움 | MiniMax가 짧게 내거나 Halo leftover를 남김 |
| 서버는 본문을 거의 유지 | `fillProductLaunchKitSlide` / leftover heal / `synthesizeTemplateCloneSlideBody`가 제목·본문을 재작성 |
| 워크스페이스·7일처럼 구체 문장이 장 전체에 유지 | Fit만 살아 있고 제목·CTA·센터 장은 `주제` 템플릿 |

이번 HTML:

- `Teamver 소개 2` — 슬라이드 번호 접미
- `주제가 해결하는 문제` / `주제의 쓰임과 근거` / `주제를 쓰기 시작한 뒤` — brief 없이 topic이 `주제`로 fallback
- `주제를 쓰는 순서를 쓰는 순서` — 템플릿 이중 연결
- `주제 다음 단계 다음 단계` — 구 중복
- `대상 고객별 메시지 실무/리더/운영` — synth lead를 topic처럼 붙여 역할 접두가 난잡
- `◎ Teamver` / `◎ Teamver을` — 브랜드 마크 + 하드코딩 `을`
- cover lede: `Teamver — 핵심 맥락과 다음 단계를 정리합니다` (루프553이 경고한 fallback. kicker와 service-intro lead가 같아 distinct lede를 합성)
- kicker `Pricing` 영어 카탈로그
- Ship CTA `시작하기`만, testimonial은 `주제를 쓰기 시작…`
- Fit의 `첫 7일` / `워크스페이스` 문장은 이미 좋음 — **유지**

## 원인

1. `resolveLockedTopicNoun`이 고유명사를 못 뽑으면 `주제`를 반환. persist leftover heal에 brief가 빠지면 cover의 `Teamver`를 무시하고 전 장 템플릿이 `주제`로 돈다.
2. `productLaunchRoleAwareTitle` / `PRODUCT_LAUNCH_GENERIC_TITLE_MAP`이 이미 있는 제목에 `${topic}이 해결하는 문제`, `쓰는 순서`, `다음 단계`를 concat. topic이 이미 그 구를 포함하면 이중 연결.
3. `productLaunchSlideNeedsHeal`이 `탐색/실행/확장` 같은 카드 라벨만 있어도 장을 refill → 밀도 있는 MiniMax 본문 옆 제목까지 템플릿으로 갈아엎음.
4. pad가 `synthesizeTemplateCloneSlideBody`로 synth 제목·본문을 넣고, `fillProductLaunchKitSlide`가 그걸 완성본처럼 저장.
5. brand에 `◎`를 다시 붙이고, generic synth lead가 `${topic}을`을 하드코딩.

## 정책

- **catalog leftover만 strip** (Halo, `$179`, 영어 earbuds, `Pricing` kicker → 빈 값. `요금` 금지. 역할에 맞는 짧은 한국어가 없으면 비움).
- 이미 한국어가 있고 **길이 ≥ 20**이면 제목/본문을 템플릿으로 재작성하지 말 것. Fit 워크스페이스/7일/권한 문장은 절대 덮지 말 것.
- topic fallback을 `주제` / `핵심 주제` / `개요`로 쓰지 말 것. brief에서 고유명사(`Teamver`)를 못 뽑으면 **제목을 비우거나 seed 원문 제목을 유지**. generic 합성 금지.
- Product Launch 제목 템플릿(`${topic}이 해결하는 문제`, `쓰는 순서`, `다음 단계` 접미)은 **끄거나 슬롯이 진짜 비어 있을 때만**. 이미 있는 제목에 concat 금지.
- `소개 ${n}`, `${title} ${n}` 숫자 접미 금지.
- 본문에서 `◎` 브랜드 마크 제거.
- `attachKoreanJosa` 유지. `Teamver을` → `Teamver를`.
- pad로 채운 장은 synth 템플릿 제목 대신 **LOOK seed 해당 슬라이드 구조+빈 슬롯**을 유지. 채울 때만 brief 한 줄.
- `주제를 쓰는 순서를 쓰는 순서` 생성 경로 삭제/가드.
