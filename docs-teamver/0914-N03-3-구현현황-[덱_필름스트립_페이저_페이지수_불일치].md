## 슬라이스 — 표지 페이지 뷰 실종 (2026-09-16)

최근 장수 동기화(`4b45b13478`)가 표지를 건너뛴 것은 아니다. 다만 페이저 SSOT가 `<section class="slide">`만 세서, Capsule `div.slide` 표지는 장수 0으로 빠지고 iframe 보고(active 0 = 실제로는 다음 페이지)를 그대로 받았다.

원인: `slide-2` 여는 태그가 없고 여분 `</div>`가 `.presentation`을 일찍 닫으면, 뒤 페이지가 `body` 직계가 된다. compact hoist의 `stackedSlideNodes()`가 그 직계만 올리고 표지는 스테이지 밖에 남긴다. CSS는 `.slide { opacity:0 }` / `.slide.active`라서 표지는 보이지 않고 `go(0)`은 다음 페이지를 칠한다. 썸네일은 슬라이드를 따로 그리므로 표지가 남아 보인다.

수정: 셸에 남은 표지를 document order로 같이 올리고, 필름스트립·페이저 장수는 `section|div.slide`를 같이 센다. 회귀: `tests/artifacts/deck-cover-page-view.test.ts`.
