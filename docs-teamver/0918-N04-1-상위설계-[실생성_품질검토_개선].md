## 목적

fixture만 보고 끝내지 않는다. **직접 생성 → 품질 검토 → 개선**.

1. Teamver Design staging(`stg-design.teamver.com`) 또는 로컬에서 brief `Teamver 소개`로 Block Frame / Cobalt Grid (가능하면 Product Launch)를 생성한다.
2. 로그인·API 키·캡차에 막히면 우회하지 않고, official LOOK seed(`plugins/_official/examples/*/example.html`)에 salvage / template-clone fill / leftover heal / persist pad를 돌려 실생성에 가장 가깝게 재현한다.
3. MiniMax 짧은 응답도 재현: seed 10장에서 section 2장만 남긴 HTML → pad+heal.
4. 미리보기(`example.html`)와 나란히 품질 표를 보고 **가장 큰 2~3개만** 고친다.
