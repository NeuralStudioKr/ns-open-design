# 0921-N05-1 상위설계 · AI fill 강제 · 서버 문장 짜맞추기 제거

> N04 는 kit copy pack Teamver-scope guard (별도 슬라이스) 로 사용됨. 같은 날 다른 주제라 N05 로 이어간다.

## 리포트 (루프562)

- 홈에서 `neuralstudio.kr 회사 사이트야. 분석해서 회사 소개 ppt 만들어줘.` 로 생성.
- 11초 만에 종료. 결과물 슬라이드가 서버 synth 문구로 도배.
  - `문제 — 사용자가과 전환 비용을 먼저 정의` ← 힐러 substring strip 잔재
  - `사용자 — 이해해야 할 제품 범위와 약속`, `대상 고객별 메시지 다음`, `측정해야 할 지표 쓰는 길`, `Neuralstudio 소개 2`
  - `Neuralstudio가 ` — 표지 subtitle 이 topic + 조사만 남기고 잘림
  - 모든 텍스트에 `data-od-hangul="1"` — Block Frame Hangul heal 전량 적용
- MiniMax 가 낸 문장이 아니라 서버 `templatesForSynthTemplateTopic` service-intro preset + `${noun}` 접미 조합 + salt suffix.

## fillMode 진단

- FE default `TEMPLATE_CLONE_FILL_DEFAULT_MODE = 'json'` (`apps/web/src/teamver/templateCloneContentFill.ts:89`).
- `getTemplateCloneFillMode()` → 사용자 override 가 없으면 `json` 반환. `shouldUsePromptTemplateCloneFill()` false / `shouldUseJsonTemplateCloneFill()` true / `shouldUseDeterministicTemplateCloneFill()` false.
- 11초 완료는 MiniMax 를 건너뛴 게 아니라 **JSON slot-fill 은 outline 만 반환** 하기 때문에 응답이 작다. AI 는 돌지만 서버가 이미 서비스-intro synth 로 seed 를 채워놓아 outline 이 짧으면 seed synth 가 그대로 노출된다.
- ⇒ **AI 는 돌고 있다.** 문제는 seed synth 의 문장 짜맞추기 + salt suffix + substring strip 잔재. **fillMode 정책은 손대지 않는다.**
