# 0805-N06-1 상위설계 — 프로젝트 썸네일 미표시 회귀

## 증상

프로젝트 목록(DesignsTab)·홈 Recent 썸네일이 갑자기 안 보임(glyph/빈 로딩).

## 원인 (가설 → 코드 확인)

1. **`ff0c7cab6`**: `useLazyProjectCover` 기본값이 embed에서 `allowFilesFallback: false`로 바뀜. 이전에는 옵션 생략 시 `/files` fallback(`true`)이었음.
2. **`da10e3d74`**: home `resolveProjectCoverOptionsForHomeSurface`도 embed hints-only로 변경 → cover-hints 미스 시 Recent도 null.
3. (보조) `ProjectCardHtmlCover` viewport defer — ref 미준비 시 observe 스킵하면 영원히 미로드 가능.

cover-hints가 비거나 실패하면 metadata `entryFile` 없는 카드는 썸네일 경로가 완전히 끊김.

## 목표

- **보이는 카드**·**홈 Recent(상한 6)** 은 hints 후 `/files` fallback 허용
- **warm/prefetch** 배치만 hints-only 유지 (부트 N+1 방지)
- HtmlCover defer null-ref harden
