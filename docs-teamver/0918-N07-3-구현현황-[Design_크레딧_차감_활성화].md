  - BYOK: commit `already_finalized`(reservation_not_found) → ledger `committed` (crash-after-commit)
  - BYOK: `proxy_sse_staged` 토큰 소스 미터링; 가격 없으면 `meter_failed` fail-closed
- ☑ **record-only staging 게이트** — DISABLED=1 + prices ON
  - kill switch 시 orphan usage_id fake-commit 금지 · BYOK resume보다 kill switch 우선 → `billing_status=disabled`
  - estimate-reserve DISABLED → `policy=billing_disabled`
  - fail-closed는 `estimateUnavailable`일 때만 (amount=0 정상 skip 허용)
- ☐ staging E2E (DISABLED=0) — 운영 키 준비 후
