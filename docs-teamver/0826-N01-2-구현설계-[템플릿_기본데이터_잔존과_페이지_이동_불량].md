#### F1-b. `.stage` / flex-track wrapper 언랩

새 함수 `hoistCloneSlidesOutOfFlexTrack(html: string): string`:

1. `<div class="stage" id="stage">` 또는 이에 준하는 flex-row 트랙 컨테이너를 찾는다.
   - 감지 기준: (a) `.stage` 또는 `.deck-stage` 또는 `id="stage"` (b) 안에 `.slide` 자식이 2개 이상 (c) inline 또는 문서 CSS 에서 `display: flex` + row 방향.
2. 안의 `<section class="slide">…</section>` 를 그대로 유지하고, wrapper 자체를 제거해 부모 (`.deck` 또는 body) 의 직속 자식이 되게 한다.
3. wrapper 가 chrome 요소도 포함하면 (`.chrome` 등) chrome 은 유지.
4. wrapper 를 감싼 `.deck` 이 위치한다면 `.deck { overflow: hidden }` 는 유지 (letterbox 시각적 프레임에 필요) — 다만 `.stage { display: flex; transition: transform }` 관련 CSS 는 host bridge 가 이 wrapper 를 track 으로 오인하지 않도록, wrapper 를 지운 뒤에도 소스에 남은 `.stage`/`#stage` CSS 규칙은 안전하다 (참조 대상이 없음).

호출 위치: `buildTemplateClonedDeckHtml` 의 마지막 (out 반환 직전, `injectTeamverSizeStyle` 앞).

경계 케이스:
- wrapper 안에 slide 외 요소 (예: `.demo-banner` 잔존) 가 있으면 언랩하지 않고 wrapper 만 유지 → 후속 stripDeckLevelDemoChrome 이 처리.
- wrapper 가 없거나 slide 를 이미 body/`.deck` 직속에 두는 템플릿은 no-op.

### F4. `stripLeftoverTemplateDemoCopy` — slot vs wrapper

클래스 목록(`alts-grid|step|stamp|…`)은 템플릿이 늘어날수록 새 wrapper 를 놓친다. placeholder Clone 본문에서는 **슬롯이 아닌 블록을 구조적으로 제거**한다.

**슬롯 (보호, 조상·자신·자손 유지)**

1. 슬라이드에서 첫 번째 `h1|h2|h3`
2. 첫 제목과 그 사이에 `h3+` 가 없는 `ul`/`ol` (카드 안 Option 리스트는 제외. Daisy/TOC 아웃라인만 슬롯)
3. `p.subtitle`
4. 제목이 없을 때만 첫 `.quote-text` / `.number` / `.caption` (title fallback 주입 자리)

일반 `p`·`.kpi`·`.num` 은 슬롯이 아니다. 이를 보호하면 IB `market-cols` 전체가 조상으로 남아 차트/카드가 다시 보인다.

**제거 대상:** `div|span|p|header|footer|aside|figure|table|section|article|svg|blockquote` 중 모든 슬롯과 disjoint 한 요소. 슬롯 안의 `em`/`i` 는 descendant 라 유지.

`Hartfield` leftover 경로도 같은 함수를 탄다. 채워진 리스트/제목은 슬롯이므로 그 조상 레이아웃(`.slide-inner` / `.body`)은 남고, 옆의 빈 카드·스탬프만 사라진다.

회귀: IB empty `maxSlides:9` 기존 assertion + 목록에 없는 `.weird-unknown-grid` 가 사라지는 합성 슬라이드.

### F6. 제목 슬롯 확장 + 구조 leftover 2차

F5 고유명사 sweep 이후에도 포스터/매거진/터미널 덱이 데모 문장을 남겼다. 원인 세 가지:

1. `h1|h2|h3` 도 `.title` 도 없는 표지 — `slots.length === 0` 이면 wrapper strip 이 early-return 해서 본문 전체가 남음.
2. 제목 슬롯 조상 안의 sibling `<dl>` / 두 번째 `<ul>` / `<pre>` 는 wrapper 태그가 아니라 strip 대상이 아님.
3. `replaceListItems` 는 첫 리스트만 비움. retro-windows agenda 두 번째 컬럼이 그대로 보임.

조치:

- 제목 슬롯 클래스: `title` / `title-main` / `hero-title` / `display` / `font-display` / `headline` / `toc-title` / `summary-header` / `fin-header`. 제목이 없을 때 첫 매치를 슬롯으로 취급.
- `slots.length === 0` early-return 제거 — leftover wrapper 는 슬롯이 없어도 삭제.
- wrapper 태그: `dl|dt|dd|ul|ol|pre|code` 추가.
- 아웃라인 리스트 슬롯은 **첫 번째만**. 두 번째 컬럼 리스트는 leftover.
- persist 지문 + `looksLikeLeftoverTemplateDemoDeck`: Apex Group / Lorem ipsum / Mina Kovac / OPERATION HALCYON / Quartz. Confluence / hermes-agent.

일반 `p` · `.number` · `.kpi` 는 슬롯이 아니다 (IB `market-cols` 회귀 금지).

### F7. AI 생성 덱 5종 회귀 salvage (Q1–Q5 · 0827)

사용자 브리프(“영어 회화 공부, 연습 팁에 대한” + ib-pitch-book 팔레트)에서 실 렌더 HTML을 첨부한 5개 회귀. `template-clone-fill.ts` 는 저자 catalog 경로만 다루므로, AI가 shell 없이 자유 emit 한 `s-cover`/`s-chapter`/`s-data` 계열 슬라이드에는 별도 heal 파이프가 필요하다.

#### F7-a. 신규 파일 — `packages/contracts/src/html/heal-ai-generated-deck.ts`

Shape-based 헬퍼 6종 + 통합 함수:

- `dropEmptyLikelyDeckSlides(html)` — 두 번째 이후 슬라이드 중 visible text < 2자 & `<svg|img|video|canvas|iframe|picture|figure>` 없음 & attrs background(-image)|gradient 없음 → drop. **첫 슬라이드는 절대 삭제 금지** (빈 커버라도 없는 것보단 낫다).
- `unnestHeadingBlockChildren(html)` — `<h1..h6>` 안에 첫 자식이 아닌 위치에 block(`div|section|aside|p|ul|ol|figure|table|blockquote|main|article|header|footer`)이 있으면 heading을 그 앞에서 닫고 block을 형제로 배치.
- `shrinkOverAllocatedRepeatGrid(html)` — `grid-template-columns: repeat(N,1fr)`에서 직접 자식 개수(depth 카운트)가 `N`보다 적으면 declared N을 자식 개수로 축소. 4-col grid에 1 card면 1-col. **자식이 없거나 `N`과 같거나 크면 변경 없음**.
- `scrubTruncatedAiTagSoup(html)` — `<h>` / `</h>` (숫자 없는 orphan heading) 제거. `h1..h6`는 손대지 않음.
- `normalizeHangulParticleGaps(html)` — `[가-힣]+\s+(을|를|이|가|은|는|에|의|과|와|도|로|으로|께|께서|한테|에서|부터|까지|만|보다|처럼|같이|마다|뿐|씩|이나|나|든지|라도|이든|든|밖에)` 사이 단일 공백을 삭제해 조사 재부착.
- `scrubBriefLeakFromMetaSlots(html, brief)` — `.v`/`.conf`/`.kicker`/`.brief`/`.summary`/`.note`/`.lede` slot 내부 텍스트가 brief와 완전 일치(공백 정규화 후)하면 innerText를 비운다. brief 길이 ≥4자일 때만.
- `healAiGeneratedDeckMarkup(html, brief?)` — 위 6개를 idempotent 순서로 실행.

#### F7-c. 사이드 이펙트 — kit-card / calc mix 확정

같은 슬라이스에서 `chat-leak-probe-round35`(ul>li 8px)와 `chat-leak-probe-round437`(mixed 12px thin) 회귀를 소진:

- `deck-fixed-canvas.ts.bindFakeOutlineCardsInSpan` — `LIST_ITEM_CARD_TAGS_RE = /^(?:li|dt|dd)$/i`. list-item 태그는 padding ≥4px 물리값(rem ≥0.25 / % ≥1) 이상이면 card 바인딩. round321/345 padding 0–2px는 여전히 회피.
- `deck-fixed-canvas.ts.calcAdditiveSameUnitLooksCardLike` — 혼합 계산 3종(`rem+px`, `view+px`, `%+px`) 규칙을 **either side ≥ threshold OR 물리 합 ≥ 13 px** 두 갈래로 이중화. 결과:
  - `.5rem+4px=12px` → 두 조건 다 false → thin (round437 SSOT).
  - `1vh+8px=18.8px` / `2%+8px=29.6px` → 물리 합 ≥13 → card (round543/544/545).
  - `.5rem+.25rem=12px` 는 same-unit 규칙이 먼저 통과해 card 유지.
- 루프435 이후 “mixed 12px = card” 세대 테스트(round467/468/470/475/476/485/489/490/493/495/515)는 round437 SSOT에 정렬 — `toMatch` → `not.toMatch` 로 뒤집었다.

#### F7-e. 안전 가드

- 모든 heal은 **저자 catalog HTML을 건드리지 않는다**. 판정 기준은 visible text/direct-child count/명시적 slot class — catalog CSS나 authored copy 형상에는 매칭되지 않는다.
- `dropEmptyLikelyDeckSlides` 는 첫 슬라이드/motif 배경/svg를 보존.
- `unnestHeadingBlockChildren` 은 heading 앞에 텍스트가 있을 때만 split (empty heading이 첫 자식으로 block을 감싸는 legit 마크업 보존).
- `shrinkOverAllocatedRepeatGrid` 는 depth-1 자식만 셈. 카드 내부 하위 div가 컬럼 수를 부풀리지 않는다.
