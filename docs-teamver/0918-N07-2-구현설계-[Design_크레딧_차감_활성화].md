## 1. 접근

신규 과금 파이프라인을 만들지 않는다. As-Is 골격(Strategy A managed · Strategy B BYOK · `TEAMVER_BILLING_DISABLED`)을 **운영 가능하게** 다듬는다.

1. env 예시·검증 문구를 “미구현” → “킬스위치로 OFF”로 정정.
2. 차감 ON 시 Registry 자격증명 필수(이미 production fail-fast) + 단가 또는 flat amount 중 하나 필수 경고.
3. MiniMax 기본 단가 예시를 `DESIGN_MODEL_PRICES_JSON`에 포함 (managed 기본 모델).
4. §4.9 CTO 보류 절을 이 에픽으로 갱신.

## 3. 데이터 흐름 (ON)

```text
managed:
  run start → estimate-reserve (prices or flat) → Registry reserve
  run end success → commit(usage_id)
  run fail → refund(usage_id)
  병행: usage/events ledger upsert

BYOK:
  message terminal PUT → finalize-byok-run
    meter(tokens) → reserve(amount_t) → commit → ledger billing_status
```
