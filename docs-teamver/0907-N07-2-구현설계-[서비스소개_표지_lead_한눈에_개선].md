## 로직

### A. Lead chooser (`chooseDeterministicSynthCoverLead`)

입력: `{ brief?, coverTitle }` → string.

```
fallback = `${topicKeywordForSynthBody(coverTitle)} 한눈에`
```

1. brief 비어 있으면 → fallback
2. brief에서 후보 수집 (`collectDeterministicSynthCoverLeadCandidates`):
   - `Brand — tagline` / `Brand - tagline` / em-dash 패턴
   - `Source preview:` 블록의 첫 usable 줄(URL·instruction·너무 짧음 제외)
   - `문제`/`병목`/`pain`/`왜` 로 시작하는 한 줄
   - `Visible/Canvas/Source headings` 중 promise-like(—, :, 영문 slogan, 가치 키워드)
3. 각 후보를 `isUsableDeterministicCoverLead`로 필터:
   - 길이 8–72 (한글 기준 대략)
   - `{topic} 한눈에` / `한눈에`만 / raw URL / instruction copy 거부
   - cover title과 동일·거의 동일 거부
4. service-intro가 아니어도 **usable 앵커가 있으면** 채택(저비용·부작용 적음). 없으면 fallback.
5. service-intro + 후보 없음 → fallback 유지(짧은 URL-only 덱 호환)

### B. 호출부 교체

`한눈에` 하드코딩을 chooser로:

| 위치 | 비고 |
|------|------|
| `synthesizeTemplateCloneOutlineFromBrief` cover slide | brief 전달 |
| `resolveTemplateCloneSlidesForDeterministicFill` densify cover | `slide.lead ?? choose…` |
| free-form last-resort cover | brief 전달 |
| `scrubLeftoverCatalogExampleHtml` synth fallback cover | brief 전달 |
| empty-brief starter cover | brief 없으면 fallback = deckTitle 한눈에 (현행) |

**유지:** sakura/lede DOM slot의 `` `${title} 한눈에` `` — slide `input.lead`가 비었을 때만 쓰는 최후 DOM filler. outline이 이미 나은 lead를 넣으면 그대로 사용됨.
