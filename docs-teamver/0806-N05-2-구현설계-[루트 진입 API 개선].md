## 현재 슬라이스 — cover-hints miss 축소 (`/files` 최후수단)

**목표:** home Recent의 cover-hints hit률을 올려 bounded `/files` fallback을 줄인다.  
`/files` fallback 자체는 0805-N06 썸네일 가드로 **유지**.

### Root cause

| 경로 | materialize / PG | cold miss 시 |
|------|------------------|--------------|
| `POST /cover-hints` | sync `getProject` only · dir `stat` 필수 | null → FE `/files` |
| `GET /files` | lazy materialize + PG hydrate | list 성공 |

### 변경

| 파일 | 동작 |
|------|------|
| `project-cover-hints.ts` | `metadata.entryFile` 있으면 **dir 없이** hint 반환. disk 있을 때만 `coverVersion` / shallow scan |
| `project-routes.ts` cover-hints | `getProjectAsync`로 PG project-row warm (conversations 등 heavy warm·`ensureMaterialized` **금지**) |
| FE | home `allowFilesFallback: true` 유지 — 진짜 miss만 `/files` |

### 의도적 비범위

- cover-hints 안 `ensureMaterialized` (S3 sync-down N개 — 더 비쌈)
- BFF registry `entryFile` 스키마 (cross-repo)

### 검증

- unit: disk 없는 entryFile → hint · PG async hydrate 경로
- staging: entryFile 있는 Recent → `/files` 0에 수렴
