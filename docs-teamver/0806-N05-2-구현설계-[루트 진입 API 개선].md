## 현재 슬라이스 — Community preview 부하 가드 + 체감

**목표:** 뷰포트 썸네일은 채우되, 동시 `/preview` 폭주·가장자리 peek GET은 막는다.

| 항목 | 동작 |
|------|------|
| concurrency | `loadPluginPreviewHtml` 동시 **최대 3** (슬롯 큐) |
| session cache | ≤180KB HTML · 최대 16개 → 홈 재진입 시 GET 스킵 |
| threshold | `!eager` near observer **0.2** — 살짝만 보이는 카드는 GET 안 함 |
| 유지 | eager=false · rootMargin 120px · batch API 없음 |

### 하지 않음

- eager/wide margin 재개
- 24장 일괄 warm / plugin-preview batch
- daemon `/preview` 대형 리팩

### 검증

- unit: concurrency peak ≤3 · session hit 시 fetch 1회
- staging: 뷰포트 카드 채움 · Network에 preview 동시 ≤3
