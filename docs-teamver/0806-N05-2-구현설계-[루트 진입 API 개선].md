## 현재 슬라이스 — Community 템플릿 상세 deck-nav

**증상:** 커뮤니티 카드 클릭 → 템플릿 미리보기에서 이전/다음 페이지 버튼이 없는 경우가 많음.  
**원인:** FileViewer는 host `.deck-nav` + `od:slide` 가 있지만, Community 상세는 `PreviewModal`이라 **호스트 크롬이 없음**. 템플릿 HTML 자체에 버튼이 없으면 키보드/제스처에만 의존.

| 파일 | 변경 |
|------|------|
| `PreviewModal.tsx` | deck 뷰에 prev / `n / N` / next · `od:slide-state` 수신 · ArrowLeft/Right |
| `PluginExampleDetail.tsx` | `deck` 판정: mode deck\|template 또는 preview.type=html |
| `composio.css` | `.ds-modal-deck-nav` 정렬 |

### 검증

- unit: deck 뷰에 `preview-modal-deck-nav` · non-deck 없음
- staging: Community 템플릿 상세에서 호스트 버튼으로 슬라이드 이동
