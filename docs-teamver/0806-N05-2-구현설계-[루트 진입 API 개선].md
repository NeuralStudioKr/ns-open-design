## 현재 슬라이스 — Community gallery 썸네일 체감 (inView arm)

**증상:** Teamver slide-only home Community 카드가 오래 비어 있거나, hover 전까지 skeleton만 보임.  
**원인 (의도적 defer + HTML fallback):**

1. `PluginCard` gallery → `eager={shouldEagerLoadCommunityPluginPreviews()}` → embed에서 **false**  
   (`embedDaemonFetchPolicy.ts` · `PluginCard.tsx`)
2. `HtmlSurface` embed + `!eager` 이면 **inView로도 GET하지 않음** — hover/`instantMount`만 arm  
   (`HtmlSurface.tsx` early return). 홈 부트 preview 팬아웃 방지(0805)용.
3. bake miss / R2 실패 시 `preferBaked`가 html `/api/plugins/:id/preview` 로 떨어지고, 위 규칙 때문에 뷰포트 안에서도 비어 있음.
4. daemon `/preview`는 후보 walk + disk read + (slides) assemble · 응답 최대 5MiB · `Cache-Control` 1d — **batch/warm API 없음** (프로젝트 `preview-url-batch`와 다름).
5. N09 chip defer는 `example-simple-deck` **detail GET** 지연 — 갤러리 썸네일과 무관.

### 바꿀 것

| 파일 | 변경 |
|------|------|
| `HtmlSurface.tsx` | embed early-return **제거**. inView linger 120ms → GET · iframe arm 180ms. |
| `embedDaemonFetchPolicy.ts` | `shouldEagerLoadCommunityPluginPreviews` **false 유지** (wide margin 금지). |
| 테스트 | embed+inView → fetch+iframe; eager=false 소스 고정. |

### 바꾸지 말 것

- `shouldEagerLoadCommunityPluginPreviews() === false` 유지 → `PreviewSurface` rootMargin **120px** (eager 480px로 되돌려 부트 시 다수 preview GET 금지).
- `instantMount`를 gallery에 걸지 않음.
- 리스트 직후 24장 일괄 warm / plugin-preview batch API **신규 금지** (N05 네트워크 예산 유지).
- N09 chip lazy GET 롤백 금지.
- daemon `/preview` 시그니처·assemble 경로 대규모 리팩 금지 (이번 슬라이스 밖).

### UX vs network (Teamver embed)

| | hover-only (현재) | inView + tight margin (권장) |
|--|--|--|
| UX | 첫 화면 빈 카드 | 뷰포트 카드만 채움 |
| Network | boot preview ≈ 0 | 최초 ~4–8 GET (120px 안) · 스크롤 시 점진 |
| 위험 | 체감 “느림/빈 썸네일” | eager=true 재개 시 팬아웃 재발 |

Baked `MediaSurface` poster는 이미 inView 로드 — HTML 경로만 막혀 있던 갭을 맞춤. R2 poster는 별도(배포 manifest/`OD_PLUGIN_PREVIEWS_*`).

### 검증

- unit: embed inView → preview GET; `eager=false` 시 wide margin 미사용(소스/테스트 고정)
- staging: Disable cache · home → 뷰포트 Community 카드가 hover 없이 채워짐 · Network에 boot 직후 preview 폭주 없음

### 비범위 (후속)

- design-templates mode 필터를 walk에 내리기
- plugin preview batch / daemon warm
- bake pipeline·R2 동기화 전체
