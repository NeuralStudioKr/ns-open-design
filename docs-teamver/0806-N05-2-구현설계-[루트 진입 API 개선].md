## 현재 슬라이스 — design-templates 스캔 캐시

**증상:** 홈에서 템플릿 목록이 오래 걸림.  
**원인:** `GET /api/design-templates?mode=deck&limit=24`도 `listSkills(DESIGN_TEMPLATE_ROOTS)`로 **전체 ~109 SKILL.md** 를 매 요청 재스캔. FE `skillsLoading`이 이 응답을 대기.

| 파일 | 동작 |
|------|------|
| `skills.ts` | `listSkills` TTL 30s + inflight coalesce · import/update/delete 시 invalidate |
| `server.ts` | listen 직후 `listAllDesignTemplates()` warm (비차단) |
| FE | 기존 30s 클라이언트 캐시 유지 |

### 비범위 (후속)

- mode/limit 조기 종료 스캔 (필터를 디스크 walk에 내리기)
- 홈 커뮤니티 **플러그인** 프리뷰 지연 (별 경로 — hover arm 이미 적용)

### 검증

- unit: TTL hit · invalidate 후 재스캔
- staging: 두 번째 home reload에서 `/api/design-templates` TTFB 급감
