## 1. 한 줄 요약

Manual Edit에서 **이미 위치 잡힌(absolute/fixed) 요소**를 선택 박스 **본체 드래그**로 옮긴다.  
결과는 기존 `set-style` 경로로 inline `left`/`top`(px)에 저장한다.

---

## 2. 사용자 문제

| As-Is (51 이후) | Pain |
|-----------------|------|
| 박스는 리사이즈 가능 | 카드·이미지·뱃지를 **눈으로 옮겨** 맞출 수단 없음 |
| absolute 요소 W/N 리사이즈 시 left/top만 보정 | “통째로 이동” UX는 없음 |
| flow 레이아웃 요소 | 이동하면 DOM 순서·마진 지옥 — 이번 범위에서 다루지 않음 |

---

## 3. 성공 기준 (제품)

1. Edit 모드에서 **이동 가능** 요소를 고르면, 핸들 **사이 본체**를 드래그할 수 있다 (커서 `move` / grab).
2. 드래그 중 미리보기가 프레임 단위로 따라오고, pointerup 시 파일에 `left`/`top` px가 반영된다.
3. preview zoom·레터박스에서도 박스가 요소에 붙는다 (51과 동일 `preview-coords`).
4. Esc로 취소 가능, autosave는 드래그 중 pause (51 resize 계약 재사용).
5. history **1 entry** (`Move: …`), undo 1스텝으로 원위치.
6. 리사이즈 핸들 드래그와 **충돌하지 않는다** (핸들 hit이 본체 move보다 우선).

---

## 4. 범위

### In scope (1차 / MVP)

| 항목 | 설명 |
|------|------|
| 자격 | `position: absolute` 또는 `fixed` 인 Manual Edit 타깃 |
| 제스처 | overlay **본체**(핸들 제외) pointer drag |
| persist | `left` + `top` px (`set-style`), 필요 시 기존 %/auto → px 스냅 |
| 좌표 | 51 `hostDeltaToContentDelta` / remasure 재사용 |
| 모드 배타 | Draw·inline text-edit 중 비활성 (resize와 동일) |

### Out of scope (1차)

- flow/`static`/`relative` 요소의 자유 이동 (re-parent, margin 해킹, DOM 순서 변경)
- 첫 이동 시 `position:absolute`로 **승격** (레이아웃 파괴 위험 — Phase 2+에서만 검토)
- 회전 / multi-select / 스냅 가이드 / 정렬 자석
- slide root(`.slide`) 이동
- AI 호출

### 스펙과의 관계

`manual-edit-mode-requirements` non-goal:

> Drag-and-drop layout editing (reposition / **re-parent**)

이번 52는 **re-parent가 아닌**, 이미 absolute/fixed인 박스의 **좌표만** 옮긴다.  
requirements에 한 줄 주석을 추가해 “absolute/fixed translate via left/top is in scope — 52”를 명시한다 (구현 PR과 동일 브랜치 가능).
