# 0916-N02-1 상위설계 — Grove 카탈로그 데모 카피 힐러 (루프538)

상위: [0916-N01-1](./0916-N01-1-상위설계-[Broadside_카탈로그_데모_카피_힐러].md) Round 1 (a).

## 문제

Broadside(N01)는 전용 leftover 힐러가 있어 persist 뒤에 SPACE10 chrome이 남으면 다시 채운다. Grove는 같은 `slide--*` 가족을 쓰지만 `applyFillHealers`에 킷 전용 경로가 없다.

공식 `example.html`이 그대로 persist되면 아래 카탈로그 데모가 사용자 브리프 덱에 남는다.

- 커버: `[Studio Name] · [Year]`, `[Presentation Title Goes Here]`, `[Prepared by]`, `[Confidential]`
- 챕터: `The landscape has shifted. Now we must decide where to stand.`
- 사이드바: `Strategy · Presentation`, `The Thesis`, `The Evidence`, `By The Numbers`
- 통계: `grove-stat-val` `73%` / `4.8×` / `#1`
- 본문: `The brands that will lead the next decade…`

`officialLookIsStudio` / `officialLookIsBroadside`는 Grove를 deny하므로 Studio·Broadside 힐러는 no-op이다. 전역 `LEFTOVER_CATALOG_PHRASE_RE`에도 Grove 문장이 거의 없다. `73%` 같은 KPI는 전역 strip에 넣으면 다른 킷의 진짜 숫자를 지운다.

## 하지 않을 것

- 성공한 topical Grove HTML을 다시 쓰지 않음. leftover 지문이 있는 슬라이드만 채움.
- fill 기본값 / LOOK merge / synth preset / JSON 기본 전환 없음.
- MiniMax live bake 없음.
- Mat / Signal / Coral / Playful / EightBit / Capsule 힐러는 다음 라운드.
- `.stat-value` 공통 helper 추출(N01 Round d) 없음. Grove는 `grove-stat-val`만 다룸.
- KPI 숫자 발명 없음. 데모 패턴만 ordinal로 내리고, `12` / `99` 같은 seed는 유지.

## 해결

1. `healGroveLeftoverCatalogCopy` — `officialLookIsGrove` guard. leftover body만 `fillStudioKitSlide` + Grove 슬롯 채움.
2. `grove-stat` — metric fill line이 있으면 대체, `73%` / `4.8×` / `#1` literal이면 ordinal, 그 외 seed 유지.
3. leftover `grove-sidebar` / leftover heading만 브리프 outline으로 교체.
4. Grove 전용 문장만 denylist·`looksLikeLeftoverTemplateDemoDeck`에 추가. `73%`는 전역 strip에 넣지 않음.
5. `applyFillHealers`에서 Broadside 다음, Creative 앞에 연결.
