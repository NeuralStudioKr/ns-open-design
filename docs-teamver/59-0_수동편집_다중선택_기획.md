## 1. 한 줄 요약

Manual Edit에서 **여러 요소를 동시에 선택**해, 공통 스타일을 일괄 적용하거나(1차), 이후 단계에서 **그룹 박스 move/resize**(2차)를 지원한다.  
개별 요소 move/resize(51–53)와 **별도 UX·상태 모델**로 분리한다.

## 3. 성공 기준 (Phase 1 — 다중 선택 + 일괄 style)

1. **Shift+click** 또는 레이어 **⌘/Ctrl+click**으로 선택 집합을 만들고 해제할 수 있다.
2. 선택 집합이 2개 이상일 때 패널은 **공통 필드만** 편집 가능(값이 다르면 mixed placeholder).
3. Apply 시 선택된 각 `data-od-id`에 `set-style`이 **배치 적용**되고, undo는 **1 revision 스텝**으로 전체 롤백한다 ([50](./50_undo_redo_설계.md) commit 단위와 정합).
4. 단일 선택 overlay(51 resize/move)는 **primary** 1개만 유지 — mult일 때는 group chrome만 표시.
5. Draw·inline text-edit·geometry gesture 중에는 mult 선택 변경이 비활성.

### Phase 2+ (별도 마일스톤)

- 그룹 bounding box move/resize (개별 origin·sticky·promote 혼합 시 정책 필요)
- 정렬·분배·스냅 가이드
- 회전 (`transform: rotate`) — 52-0 non-goal 유지

## 4. 범위

### In scope — Phase 1 (MVP)

| 항목 | 설명 |
|------|------|
| 선택 모델 | `selectedIds: string[]`, primary = 마지막 클릭 |
| 입력 | iframe `od-edit-select` + 레이어 행 mult modifier |
| 패널 | TYPOGRAPHY / FILL / SIZE 등 **공통 style** 일괄 apply |
| history | flush 1회 → revision 1 entry (N개 patch를 한 label로 묶음) |
| 배타 | manual edit geometry session 중 selection 변경 금지 |

### Out of scope — Phase 1

| 항목 | 이유 |
|------|------|
| 그룹 박스 drag-resize | origin·promote·deck fit-scale handoff 복잡도 — Phase 2 |
| re-parent / DOM 순서 | requirements non-goal |
| mult content/html/attributes 탭 | 파손 위험 — style만 |
| AI 호출 | Edit 경계 유지 |

## 5. 아키텍처 스케치

```
Host (FileViewer)
  selectedManualEditTargets: ManualEditTarget[]
  primaryTargetId: string | null
  multSelectMode: 'replace' | 'toggle' | 'add-range' (future)

Bridge
  od-edit-select { id, additive?: boolean }
  od-edit-targets (unchanged broadcast)

Panel
  mixed-value detection per style key
  applyManualEditBatch([{ id, kind: 'set-style', styles }], label)

Overlay (Phase 1)
  union bounding rect (dashed) — no resize handles
  Phase 2: group transform session (51 session 패턴 재사용 검토)
```

**51–53 geometry handoff와의 관계:** mult 선택 시 `ManualEditResizeOverlay`는 **union chrome만** — per-target overlay는 primary 1개 또는 off. group transform 착수 전까지 resize/move 핸들은 노출하지 않는다.
