## 임의 폴백 금지 + 빈칸 제거(박스 수 조절) + 9/4 품질 기준선 (2026-10-08)

### 정책 (사용자 지시 통합)
1. **임의(하드코드/합성/topic-neutral) 문장 주입 금지.** Teamver 주제여도 하드코드
   카탈로그 폴백 금지. 적절한 내용은 **덱 안(사용자 브리프·모델 원문·슬라이드 제목·
   카드 텍스트)** 에서만 가져온다.
2. **빈칸을 남기지 않는다.** 채울 적절한 내용이 없으면 **박스/그리드/노드를 줄여**
   빈칸이 없게 한다(예: 카드 2개면 g2, 3번째를 지어내지 않음). **slide 수는 줄이지
   않는다**(slide-count 게이트 유지).
3. **모델이 쓴 on-topic 본문은 얇게 깎지 않는다.** 오히려 보존·활용해 밀도를 유지.
4. **9/4(2026-09-04) 수준 밀도·배치가 목표.** 단, 밀도의 출처는 모델 저작 콘텐츠
   보존이며 임의 합성이 아니다.

### 근본원인 — 9/4(밀도 높음) vs 현재(얇음)의 경로 차이
