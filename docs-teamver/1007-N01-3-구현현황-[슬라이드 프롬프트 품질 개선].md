## 구현

- ☑ JSON slot-fill · HTML prompt-fill 양쪽에 unique-slot 한 줄, kicker 유일성 한 줄, 3–4 아이템
- ☑ topic-lock: JSON은 전문, prompt-fill은 KPI 문장 제외(기존 KPI 줄 1회)
- ☑ slide-count 문구(keep-count / EXACTLY N / seed-header) 유지, 새 줄과 인접
- ☑ `jsonSlotFill` 턴 deliverable을 `{` JSON outline으로 교체. 채팅 버블 JSON 금지는 유지. HTML prompt-fill은 JSON outline 금지 유지
- ☑ 채팅 sanitizer는 `{title, slides, kicker/roleHint}` 를 지우고, 호스트 `parseTemplateCloneDeckOutline` 은 같은 payload를 유지
- ☑ music/deco 글리프 한 줄을 fill 빌더와 이모지 금지 옆에 추가. 다른 킷 HTML heal은 넓히지 않음
- ☑ product-launch g3→g2 shrink 제거. 2카드는 unused-title 풀로 3카드+g3. 풀 소진 시 g3 유지. 가격·KPI 미생성
- ☑ fillMode 기본값 `json` 미변경
