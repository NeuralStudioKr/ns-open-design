# 0917-N24-3 구현현황 · 저밀도/대비 품질 가드

## 사용자 증상

- 어두운 슬라이드에서 핵심 제목이 거의 검게 렌더링되어 읽을 수 없음.
- 3열 카드가 모두 존재해 구조 검사는 통과하지만, 각 카드 본문이 한 줄짜리 데모 캡션에 그쳐 결과물 밀도가 지나치게 낮음.

## 근본 원인

1. `findDeckSparseContentEvidence`는 카드 본문이 완전히 비었거나 6자 미만인 경우만 검출했다. 따라서 `문제와 환경을 이해`처럼 짧지만 비어 있지 않은 문장은 완성된 콘텐츠로 오인됐다.
2. 기존 대비 보정은 `data-od-official-look-css`가 있는 템플릿에 집중돼 있었다. 자유 생성 덱에서 `.slide`와 `.hero` 클래스가 각각 어두운 배경/어두운 글자색을 지정하면 마지막 보정이 실행되지 않았다.

## 구현

- 3~6개 카드 행에서 카드 본문 대부분이 32자 미만이거나 전체 본문이 96자 미만이면 `low_density_card_row`로 기록한다.
- 해당 슬라이드만 `deck-patch`로 재요청하고, 카드 수와 레이아웃은 유지하면서 각 카드에 근거·작동 방식·예시·결과를 35~90자로 채우도록 한다.
- 공식 LOOK 메타데이터가 없는 덱도 단순 CSS/인라인 스타일에서 슬라이드 배경과 `h1`~`h3` 색을 해석한다.
- 대비가 3:1 미만이면 더 높은 대비를 내는 흰색/검정색을 제목의 인라인 중요 스타일로 적용한다.
- 장식 motif와 이미 읽을 수 있는 제목은 변경하지 않으며, 반복 실행 결과가 동일하도록 구현했다.
