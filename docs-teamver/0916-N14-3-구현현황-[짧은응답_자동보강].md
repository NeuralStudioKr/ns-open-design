## 남은 리스크

- pad slide는 synth 문장 (topic 파생) — 밀도가 real content 대비 낮음. 사용자에게
  경험상 "저장은 되지만 뒷 슬라이드 품질은 얕음". 품질 개선은 별도 병렬 슬라이스에서.
- warn 배너는 `surfaceChatVisibleError` 채널을 재사용해 error state를 세팅.
  UI에선 error와 유사하게 보일 수 있지만 배너 카피가 "저장했다"를 명시해 사용자
  혼동을 방지. 향후 별도 warning 채널 도입 시 severity에 맞춘 UI 스타일 분리.
- warn severity 케이스에서 UI banner 스타일 자체는 error-style. 추후 별도
  notice channel 도입 시 시각적 구분 강화 필요.
