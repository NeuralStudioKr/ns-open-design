상위: [0805-N01-1](./0805-N01-1-상위설계-[채팅%20UI%20토스트·파일%20액션%20폴리시].md)

## 데이터·상태 흐름

```text
ChatComposer/FileViewer/App
  → onShowToast / teamverUiToast
  → Toast (tone, ttl, action)
  → .od-toast-anchor (position) > .od-toast (surface + Motion)

Memory extract SSE → MemoryToast → .od-memory-toast
ProducedFiles / FileOpsSummary → Open only → onRequestOpenFile(path)
```

## Toast 표면 토큰

| tone | border | background | color | icon |
|------|--------|------------|-------|------|
| default / loading | `--border` | `--bg-elevated` | `--text` | loading: `--accent` spinner |
| success | `--green-border` | `--green-bg` | `--text` | `--green` |
| error | `--red-border` | `--red-bg` | `--text` | `--red` |

compact green ring은 `.layout-compact.tone-success`에만 적용.

## 버튼 상태

```css
.od-toast-action / .od-toast-dismiss:
  transition: background/opacity --dur-quick --ease-out
  :hover → fill secondary tint
  :active → stronger fill
  :focus-visible → outline 2px --accent, offset 2px
```

## Motion vs CSS

- 앵커 `.od-toast-anchor`: `left:50%; transform:translateX(-50%)` 전담.
- `.od-toast`는 Motion `toastSlideUp`(y/scale/opacity)만 사용. CSS keyframes transform 제거.
- `.leaving`은 opacity 페이드만 (EXIT_MS 계약 유지).

## loading TTL

```ts
const effectiveTtl = code || tone === 'loading' ? 0 : ttlMs;
// aria-busy={tone === 'loading'}
```

## ProducedFiles / FileOps

- download 링크·`projectFileUrl` 제거 (유지).
- Open: `aria-label={t('tool.openInTab', { name })}` (+ title 동일).
- `.produced-file:hover` / `.file-ops-row:hover` 배경 제거.
- Open 버튼 `min-height: 28px` + accent hover/active/focus-visible 정렬.

## MemoryToast

- 인라인 hex → `.od-memory-toast` 클래스, elevated 패널 + shadow 토큰.
- clickable일 때 hover/active/focus-visible 명시.

## 검증

- Toast: loading pin, aria-busy, success/error class tokens (소스/렌더).
- ProducedFiles: no downloadFile; Open aria-label 소스 또는 RTL.
- FileOpsSummary: aria-label 존재.
