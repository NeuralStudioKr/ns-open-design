# 0914-N03-1 상위설계 — 덱 필름스트립 ↔ 툴바 페이저 페이지 수 불일치

## 문제

필름스트립(페이지 칩)에는 N+1장이 보이는데 툴바 `< >` / `N / M`은 M=N으로 막혀 next가 disabled.
실측 예: 칩 10 · 카운터 **9 / 9** · 9번 칩 하이라이트 · 본문 제목은 10번 라벨.

## 원인 (확정)

| UI | SSOT |
|---|---|
| 필름스트립 | 호스트 HTML `extractTopLevelSlideSections` (`listDeckFilmstripItems`) |
| 툴바 페이저 | iframe deck-bridge `slides().length` → `od:slide-state.count` |

`slides()`는 structured 직계 셀렉터가 **1개라도** 잡히면 fallback(전역 `.slide`)을 타지 않음 → wrapper 안에만 있는 추가 `.slide`는 카운트에서 빠져 **칩 > 카운터**.

## 목표

1. bridge `slides()`가 structured undercount 하지 않음 (전역 `.slide`가 더 많으면 그쪽 사용)
2. 호스트: HTML 섹션 수 ≠ `slideState.count`면 즉시 재동기 (방어)

## 비범위

- 필름스트립 칩을 DOM 수에 맞춰 줄이기 (사용자가 보는 HTML과 어긋남)
- WorkspaceTabsBar (워크스페이스 탭 — 무관)
