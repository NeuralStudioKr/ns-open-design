# 0917-N27-3 구현현황 — healer가 MiniMax 문장을 주제-템플릿으로 덮지 않게 한다

## 대체 뭐가 문제인가

v1.4.15는 MiniMax가 LOOK seed 10장을 직접 채운 결과였다. 지금은 모델이 짧게 내거나 Halo leftover가 남으면 leftover heal이 brief 없이 `주제`로 fallback한 뒤, `fillProductLaunchKitSlide` / `synthesizeTemplateCloneSlideBody`가 `${topic}이 해결하는 문제`, `쓰는 순서`, `다음 단계`를 이미 있는 제목·본문에 덮어 완성본처럼 저장한다. Fit의 워크스페이스·첫 7일 문장은 MiniMax가 쓴 구체 문장이라 밀도가 살아 있고, 제목·커버 lede·Ship CTA·센터 장만 템플릿 쓰레기가 된다. 장수가 맞아도 품질이 떨어진 이유는 모델이 나빠져서가 아니라, 짧은 응답을 살린다는 힐러가 문장을 다시 썼기 때문이다.

| | v1.4.15 | 지금(수정 전) | 이 슬라이스 |
|---|---|---|---|
| MiniMax | seed 10장 직접 채움 | 짧거나 leftover | 동일 (persist/pad 강제 불변) |
| 힐러 | 본문 유지 | 제목·본문 템플릿 재작성 | catalog leftover만 strip, 한국어≥20 유지 |
| 결과 | 구체 문장 | `주제` / `소개 2` / 이중 연결 | 아티팩트 제거, Fit 문장 그대로 |
