## 근본 원인 재정의

`git show v1.4.15:apps/web/src/components/ProjectView.tsx | grep findClientSlideCountRegression` 로 확인한 결과 v1.4.15 시점에도 slide-count 가드는 존재했고 지금 코드와 로직이 **동일**하다 (루프545에서 low-substance bypass만 추가 = strictly more permissive). 즉 **가드 자체는 회귀 원인이 아니다**.

진짜 회귀 원인은 v1.4.15 이후 도입된 **프롬프트 지시**가 모델의 출력을 짧고 왜곡되게 몰았기 때문:

- **v1.4.15 시점 `prompts/deck-quality.ts` exports 4개** — CONTENT_EXPANSION / EXAMPLE / LAYOUT_VARIETY / COPY_DENSITY.
- **HEAD** — 여기에 UNIQUE_SLOT_COPY + TOPIC_LOCK이 추가됐고, 특히 UNIQUE_SLOT_COPY는 `A deck where a majority of body slides share the same body sentence is a failed deliverable` 같은 **penalty framing**이 담겨 있어 모델이 이를 회피하려 슬라이드를 통째로 드롭 (`slide-count` 가드에 걸림).
- 루프545에서 `Keep the template's slide count — do NOT drop or merge slides…`를 같은 상수에 append했지만, 상충 지시 두 개가 한 상수 안에 공존해 모델 순응이 흔들림.

## 원복 결정

1. **`SLIDE_DECK_UNIQUE_SLOT_COPY_INSTRUCTION` 소프트닝**
   - `failed deliverable`, `majority of body slides share the same body sentence` 같은 penalty framing 제거.
   - Bare-one-word-label 금지 · 슬라이드 제목=본문 금지 등 밀도 지시는 유지.
   - **장 수 유지 지시는 별도 상수 `SLIDE_DECK_KEEP_SLIDE_COUNT_INSTRUCTION`으로 분리**해 상충 지시 공존을 해소. `templateCloneContentFillHardRules` / `buildTemplateClonePromptFillSeed`에서 새 상수를 별도 라인으로 emit.
2. **`SLIDE_DECK_TOPIC_LOCK_INSTRUCTION` 유지**
   - v1.4.15 시점에는 없었지만, `개념 / 구조 / 영향` 같은 주제 무관 일반론 금지 + 지어낸 KPI 금지 + 카탈로그 데모 문구 금지는 사용자 원칙("본문 자체 품질")과 일치하고 penalty framing이 아니어서 유지.
3. **rotation salt 함수 · healer 유지**
   - 루프545에서 이미 salt 삽입 로직은 제거됐고 healer만 방어용으로 남았다. v1.4.15 동작에 이미 정렬. 유지.
4. **`findClientSlideCountRegression` low-substance bypass 유지**
   - v1.4.15보다 permissive한 방향이라 사용자 원칙과 일치. 유지.
5. **기타 fix (카탈로그 스크럽, 8-bit 슬롯, block-frame 힐러, kit-specific topic-aware fallback) 유지**
   - 모두 결과물 품질을 올리는 방향이라 되돌리지 않는다.

## 문구 재작성 (사용자 지시대로 penalty framing 제거)

### Before (루프544 + 루프545)

```
Unique-per-slot copy is REQUIRED: each card / list item / stat / step / quote body must be a DIFFERENT concrete 1–2 sentence line.
Do not repeat the slide title as its body. Do not stamp the same lead/body across multiple slides — if two slides would end up with identical body strings, rewrite one with a distinct angle.
Bare one-word labels (핵심, 개념, 요약, 특징, 목표, 방향) as body copy are forbidden — expand to a real sentence about THIS slide's angle.
A deck where a majority of body slides share the same body sentence is a failed deliverable.
Keep the template's slide count — do NOT drop or merge slides to satisfy uniqueness. Preserve every `<section class="slide">` shell shipped in the seed and fill it with a distinct angle instead of shrinking the deck.
```

### After (루프546)

```
SLIDE_DECK_UNIQUE_SLOT_COPY_INSTRUCTION =
"Each card / list item / stat / step / quote body should be a concrete 1–2 sentence line — prefer a distinct angle per slot over stamping the same lead across multiple slots. "
"Do not repeat the slide title as its body. "
"Bare one-word labels (핵심, 개념, 요약, 특징, 목표, 방향) as body copy are too thin — expand to a real sentence about THIS slot's angle."

SLIDE_DECK_KEEP_SLIDE_COUNT_INSTRUCTION =
"Deliver the same number of `<section class=\"slide\">` slides as the seed. If two slots would repeat, rewrite one with a different angle — do not merge or drop slides."
```

2. 신규 `SLIDE_DECK_KEEP_SLIDE_COUNT_INSTRUCTION`가 export되고 prompt seed / JSON slot-fill hard rules 양쪽에 별도 라인으로 삽입됨.
3. `SLIDE_DECK_TOPIC_LOCK_INSTRUCTION` 그대로 유지.
4. synth body에 salt 토큰 없음 (기존 루프545 pin 유지).
