# 0805-N02-1 상위설계 — 채팅 UI 인터랙션·CTA 폴리시

**날짜:** 2026-08-05  
**선행:** [0805-N01](./0805-N01-1-상위설계-[채팅%20UI%20토스트·파일%20액션%20폴리시].md)  
**범위:** 채팅 아티팩트 카드·Questions 배너·에러/AMR CTA·jump·composer ghost (저위험)

## 문제

1. 빈 채팅 디자인 아티팩트 카드가 `role=button`인데 마우스는 더블클릭만 Open → 클릭 가능처럼 보이나 무반응.
2. answered Questions 배너가 `disabled` + 전역 opacity 0.5로 이중 뮤트.
3. `.chat-error-action` / `.amr-card__cta`에 `:active`·명시적 `:focus-visible` 없음.
4. jump-to-latest에 `:active`·`aria-label` 부족.
5. composer import/research ghost에 press/focus 피드백 비대칭.
6. 에러 카드 ghost(copy/retry)에 `:active` 공백.

## 목표

N01과 동일 토큰 패턴(hover / active / focus-visible)으로 채팅 인터랙션 일관성 정렬. 레이아웃 재설계 없음.

## 성공 기준

| # | 기준 |
|---|---|
| S1 | openable 아티팩트 단일 클릭 Open + hover는 interactive만 |
| S2 | answered banner `disabled`여도 opacity 1·cursor default |
| S3 | error/AMR primary CTA에 active + focus-visible |
| S4 | jump 버튼 active + aria-label |
| S5 | composer import/research active + focus-visible |
| S6 | error ghost active + focus-visible |
| S7 | 관련 Vitest 통과 |
